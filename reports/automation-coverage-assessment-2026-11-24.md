## Method and limitations

- Retrieved 294 current cases using the repository TestRail exporter and 177 current sections using the same `.env` configuration and read-only TestRail API authentication. Credentials were not printed or copied into the report.
- Case IDs, titles, preconditions, separated steps, expected results, test data, references, priority IDs, and section IDs are in the ignored `.testrail-cases.json` export. Section names and hierarchy are from the current sections API response. This report lists the current title and section with test-data presence rather than reproducing potentially sensitive case data.
- Existing automation mappings and prior run claims were reconciled against active `tests/` and `testdata/` IDs, `reports/automation-traceability-matrix.csv`, and `TESTRAIL_TRACEABILITY_MATRIX.md`. The local pass evidence is historical; tests were not run for this assessment.
- The existing local report and mapping can contain stale test titles or classifications. Current case title/section are taken from this fetch; the local mapping is used only for automation and prior execution classification.
